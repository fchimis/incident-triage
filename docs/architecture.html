Incident Triage — GCP Architecture

One incident's journey across five swimlanes. Gemini appears three times: Flash triages every incident, Pro escalates the low-confidence cases, and Pro-as-Judge scores quality in the nightly evaluation loop.

What each box does

1 · Ingest

Cloud Run — Ingest validates the incoming JSON and pushes the raw text to GCS (CMEK, 30-day retention) plus an event to Pub/Sub incidents.raw. Ingest and processing are decoupled so a Gemini quota blip can't drop incidents.

2 · Prepare

Cloud Run Worker pulls from the topic. Cloud DLP inspects for PII, then the in-process regex layer redacts card numbers, IPs, emails, JWTs and API keys before any Gemini call. Secret Manager holds the Vertex service account.

3 · Reason with Gemini

Gemini Flash triages every incident with response_schema constrained to the taxonomy. If confidence < 0.60 or category is unknown, the worker escalates to Gemini Pro. Pipeline Guardrails then force review on PII, security, low-confidence and unknown categories.

4 · Persist & Route

BigQuery stores every triage decision (day-partitioned, category-clustered) — this is the eval source of truth. Pub/Sub incidents.triaged fans out to the ticket router. Anything the pipeline defers goes to the Human Review Queue; unrecoverable errors go to the DLQ.

5 · Operate — Gemini in the loop

Cloud Logging + Cloud Monitoring track deferral rate, P1 rate, latency, DLQ depth. Gemini Pro as Judge scores next_action quality and rationale groundedness on the golden set nightly — a > 5 % accuracy drop pages the on-call rotation.

Human-in-the-loop

Deferrals get reviewed. So does a 2 % random sample of confident predictions — the only way to catch over-confident errors the model would otherwise slip past. Every reviewer decision becomes a labelled record and appends to the golden set.

Service choices & alternatives

ChoiceWhy over the obvious alternative
Cloud Run for ingest + workerRequest-based autoscaling for bursty traffic; container gives full control over the Python runtime. Cloud Functions Gen 2 works too; Run scales more predictably at 1000s/day.
Pub/Sub as queue + DLQAt-least-once delivery, native dead-letter topic — safer failure handling than Cloud Tasks.
Cloud DLP before GeminiCatches PII formats the in-process regex misses. The regex is defence-in-depth for the synchronous path.
Vertex AI GeminiVPC-SC, CMEK, IAM, audit logs, no data-for-training — needed for enterprise incident data. AI Studio is easier but not enterprise-grade.
Flash → Pro fallback~90 % of triage is straightforward classification. Flash handles the bulk; Pro handles the uncertain ~10 % — cost/quality tradeoff made explicit.
BigQueryStructured results, eval history and the golden set live in one warehouse — no glue code to move data between stores.
Gemini-as-Judge for evalDeterministic metrics like F1 can't score open text like next_action. A second Gemini call with a rubric can — the "observability" story for LLM outputs.
